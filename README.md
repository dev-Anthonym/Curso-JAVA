## 📌 Sobre o projeto

Estou fazendo o curso **Java COMPLETO Programação Orientada a Objetos + Projetos** na Udemy, com foco em lógica de programação, orientação a objetos e desenvolvimento de projetos em Java.

📅 Minha rotina de estudos é diária. Além de acompanhar as aulas, toda semana desenvolvo um pequeno sistema por conta própria, sem seguir o passo a passo do curso, para treinar a resolução de problemas e fixar o que aprendi.

## 📂 Organização

Todo o código fica em `src/main/java/`. Cada módulo reúne os exercícios da seção correspondente do curso, e a pasta **Projetos** guarda os sistemas que desenvolvo por conta própria.

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/dev-Anthonym/Curso-JAVA.git
   ```
2. No Eclipse, vá em **File → Import → General → Projects from Folder or Archive** e selecione a pasta `Curso-JAVA`.
3. Abra qualquer arquivo `.java` e execute com **Run As → Java Application**.
